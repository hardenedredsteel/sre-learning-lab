# SRE Lab

Учебный стенд для практики Linux, сетей, Docker, Ansible и troubleshooting.

## Цели

- уверенно диагностировать проблемы Linux-сервера;
- автоматизировать базовую настройку через Ansible;
- понимать маршрутизацию, DNS и TCP;
- собирать и анализировать логи;
- документировать инциденты и восстановление.

## Среда

- VPS: KVM, Datacheap, NL
- ОС: Ubuntu 24
- Доступ: SSH по Ed25519
- Управление: Ansible
- Контейнеризация: Docker
