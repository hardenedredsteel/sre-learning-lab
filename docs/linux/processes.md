# Процессы: базовая диагностика

## Цель
Быстро понять, какой процесс потребляет CPU/память и как его безопасно остановить.

## Симптомы
- Сервер «тормозит», SSH отвечает медленно.
- Мониторинг показывает высокий CPU или память на хосте.

## Команды проверки

```bash
# Общая картина по CPU и памяти
top -bn1 | head -n 20

# Более удобный вывод (если установлен)
htop

# Процессы, отсортированные по CPU
ps aux --sort=-%cpu | head -n 10

# Процессы, отсортированные по памяти
ps aux --sort=-%mem | head -n 10
```

## Как читать вывод

- `top`: строка `%Cpu(s)` показывает загрузку CPU, строки процессов — `%CPU` и `%MEM`.
- `ps aux`: столбцы `%CPU`, `%MEM`, `COMMAND`.

## Безопасное исправление

```bash
# Мягкая остановка процесса по PID
kill <PID>

# Принудительная остановка (если не реагирует)
kill -9 <PID>
```

## Проверка результата

```bash
ps -p <PID>
top -bn1 | head -n 5
```

## Типичные ошибки

- `kill -9` без попытки обычного `kill`.
- Остановка системных процессов без понимания их роли.
